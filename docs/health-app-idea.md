# ไอเดียแอปสุขภาพส่วนตัว (ยังไม่เริ่มทำ)

> บันทึกเมื่อ 19 พ.ย. 2026 · สถานะ: **รอข้อมูลก่อนเริ่ม**
> แรงบันดาลใจ: แอป WiseMeal (ทำแอปของเราเอง ไม่ลอกแบรนด์หรือดีไซน์)

## เป้าหมาย
แอปช่วยดูแคลแต่ละมื้อ ถ่ายรูปอาหารด้วยมือถือแล้วให้ AI ประเมิน วางแผนการลดน้ำหนัก และดูแลสุขภาพแบบครบวงจร

## รูปแบบแอป
- เว็บแอปแบบ PWA กด "Add to Home Screen" บน iPhone ได้ ไม่ต้องมี Mac หรือบัญชี Apple Developer
- สแกนรูปใช้ Claude API (ต้องมี API key จาก Anthropic Console ซึ่งคิดเงินแยกจากแพ็กเกจ Claude)
- ต้องมีฟังก์ชันฝั่งเซิร์ฟเวอร์ (Netlify/Cloudflare ฟรี) ไว้ซ่อน API key
- ค่า API ใช้คนเดียววันละ 3–5 รูป ประมาณหลักสิบบาทต่อเดือน (ประมาณการ ต้องเช็กราคาจริง)
- ความแม่นยำจากรูปคลาดเคลื่อนได้ราว ±20–30% (ประมาณการ) จึงต้องให้แก้ตัวเลขเองได้ และมีตัวเลือก เช่น "มันมาก" หรือ "ข้าวครึ่งจาน"

## เฟส 1 – ใช้งานได้จริง (1–2 วัน)
- [ ] โปรไฟล์ (เพศ อายุ ส่วนสูง น้ำหนัก กิจกรรม เป้าหมาย) คำนวณ TDEE และแคลเป้าหมายต่อวัน
- [ ] ถ่ายรูปอาหาร ให้ AI ประเมินแคล โปรตีน คาร์บ ไขมัน แก้ไขได้ แล้วบันทึกมื้อ
- [ ] หน้าวันนี้: วงแหวนแคลที่เหลือ และ macros
- [ ] พิมพ์ชื่ออาหารแทนรูปได้ (เช่น "กะเพราหมูสับไข่ดาว")

## เฟส 2 – ติดตามผล (2–3 วัน)
- [ ] บันทึกน้ำหนัก กราฟ BMI เส้นเป้าหมาย
- [ ] จับเวลา IF (16:8, 18:6, ...)
- [ ] ประวัติรายวันและรายสัปดาห์

## เฟส 3 – ผู้ช่วยสุขภาพ (ทีหลัง)
- [ ] AI วางแผนการลดน้ำหนัก แนะนำเมนูตามแคลที่เหลือ
- [ ] สรุปรายสัปดาห์
- [ ] สแกนบาร์โค้ด (Open Food Facts)
- [ ] บันทึกน้ำ การนอน การออกกำลังกาย
- [ ] ซิงก์ข้ามเครื่อง

## คำถามที่ต้องตอบก่อนเริ่ม
1. เป้าหมาย: ลดกี่กิโล ในกี่เดือน หรือเน้นสร้างกล้ามเนื้อ
2. ภาษา: ไทย อังกฤษ หรือทั้งสองภาษา
3. ต้องการฟีเจอร์ IF ไหม
4. ใช้คนเดียว หรือแชร์ให้คนอื่นใช้ด้วย (ถ้าแชร์ต้องมีล็อกอิน)
5. พร้อมสมัคร Anthropic Console ไหม หรือให้เฟสแรกใช้การพิมพ์ชื่ออาหารแทน (ไม่มีค่าใช้จ่าย)

## ข้อมูลอ้างอิงตอนนี้ (จากภาพหน้าจอ)
- น้ำหนัก 68.5 kg, BMI 24.6
- เป้าหมายแคลใน WiseMeal: 1590 kcal/วัน (คาร์บ 179g, โปรตีน 99g, ไขมัน 53g)
- IF: 16:8 (18:00 → 10:00)
- ใช้ iPhone
